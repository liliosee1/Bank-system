# IronClad Banking System

The IronClad Banking System is a JavaScript-based banking simulation project
designed to practice core programming concepts through real-world banking scenarios. 
The system demonstrates the use of functions, conditions, loops, arrays, and multiple JavaScript array methods while simulating common banking operations.
# Project Features
#Smart ATM & Transaction History
- Starts with an account balance of $1000
- Supports deposits and withdrawals
- Stores transaction records
- Includes undo functionality for reversing the last transaction
- Applies maintenance fees
- Automatically manages transaction history size
# Loan Processing System
Processes customer credit scores using JavaScript iteration methods:
- Filters eligible applicants
- Adjusts scores
- Calculates total risk metrics
- Checks for perfect scores
- Validates minimum requirements
- Finds high-risk applications
# Fraud Detection & Ledger Auditing
Security tools for transaction monitoring:
- Detects flagged fraud IDs
- Finds transaction locations
- Reviews recent transaction records
- Removes fraudulent transactions
- Clears safe transactions
# Bank Merger & Data Cleanup
Handles customer database operations:
- Merges customer records
- Cleans nested data
- Sorts and reverses customer lists
- Creates welcome banners
- Initializes teller window status
# Security & Reporting System
- Validates passwords using security rules
- Generates yearly audit reports
- Detects leap years
- Tracks anniversary milestones
